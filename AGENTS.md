# Project Agent Notes

## Design References

This project includes a local copy of VoltAgent's `awesome-design-md` design reference collection at:

```text
design-skills/awesome-design-md
```

When a task asks for UI/UX redesign, product polish, visual direction, or "Meta product level" quality, read:

```text
design-skills/awesome-design-md/SKILL.md
```

Then choose a specific reference from:

```text
design-skills/awesome-design-md/references/design-md/<slug>/DESIGN.md
```

Do not blindly copy brand identity, logos, trademarks, or marketing copy. Use the selected `DESIGN.md` as a visual-language reference and adapt it to Hong Kong Buddy's product priorities: Cantonese learning habit first, daily-life translation second.
