# Awesome DESIGN.md Project Index

Source: `VoltAgent/awesome-design-md`, copied into this project for local UI/UX reference use.

## How To Choose

- Conversation or support UI: `intercom`, `slack`, `superhuman`
- Calm learning or premium consumer UI: `apple`, `notion`, `airbnb`
- AI or model-provider surfaces: `minimax`, `claude`, `elevenlabs`, `mistral.ai`, `together.ai`
- Developer or technical dashboards: `linear.app`, `vercel`, `mintlify`, `cursor`, `warp`
- Community or service trust: `airbnb`, `intercom`, `wise`
- Marketing landing pages: `apple`, `stripe`, `webflow`, `framer`
- Avoid by default for Hong Kong Buddy: heavy automotive luxury, crypto/trading density, retro nostalgia, and dark-neon systems unless the user asks for that style.

## Recommended For Hong Kong Buddy

1. `intercom`: primary reference for the visit interpreter and conversational support feel.
2. `apple`: secondary reference for calm whitespace, restrained controls, and premium polish.
3. `notion`: secondary reference for phrasebook, notes, and learning-path organization.
4. `airbnb`: secondary reference for warm community-visit trust screens.
5. `linear.app`: admin/status/dashboard reference only.
6. `minimax`: provider-brand or AI-quality section reference only, not the default app shell.
